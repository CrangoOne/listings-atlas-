# Listings Atlas (public Pages pack)

Copy the contents of this folder to the public repo
https://github.com/CrangoOne/listings-atlas- (repo root), then enable
GitHub Pages from branch `main` / root.

Site URL once enabled: https://crangoone.github.io/listings-atlas-/

For Explore/row filters on a phone: download
`daq/merged/20261108_all_car_listings.db` from the private Cursor repo
and use **Load local .db**.
